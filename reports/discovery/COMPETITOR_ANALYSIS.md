## Positioning decisions

- Lead with **session-based cleanup of live development resources**. Show a finished session linked to the server, file watcher or headless browser it left behind, then show the stop preview. Credit port-first tools with overlapping capabilities. SpawnSweep’s model also surfaces unmatched resources and recognizes pins and protected ports. [SpawnSweep scanner](../../Sources/SpawnSweep/Engine/Scanner.swift) · [App action previews](../../Sources/SpawnSweep/App/AppModel.swift)
- Connect memory recovery to concrete actions such as stopping a dev server or shutting down an iOS simulator. Explain storage recovery separately through worktree Slim, Recycle and eligible device removal. Avoid reporting file size as recovered disk space before measurement. [Cleanup actions](../../Sources/SpawnSweep/Engine/Actions.swift) · [Disk scanner](../../Sources/SpawnSweep/Engine/DiskScanner.swift)
- Explain how Recycle preserves a branch and retains selected ignored files for the configured restore window. Show that Slim has different consequences from removing the entire checkout. This is a useful distinction even when a competitor offers its own recovery flow. [Worktree actions](../../Sources/SpawnSweep/Engine/Actions.swift)
- Compare tools by workflow, OS support and license. Give MacPaw credit for developer cache cleanup and mention that SpawnSweep’s Docker workflow stops detected running stacks without pruning volumes. Document the optional Claude Code hook and read-only MCP integration as separate from interactive cleanup. [SpawnSweep CLI](../../Sources/SpawnSweep/App/CLI.swift) · [MacPaw developer CLI](https://macpaw.com/news/cleanmymac-cli)
- Build on the existing OpenMacApps result. A maker Product Hunt listing, GitHub Releases and independent coverage can give engines additional citation sources. Measure each placement after it is approved and live. [SpawnSweep listing](https://openmacapps.com/apps/spawnsweep/) · [Sluice launch example](https://www.producthunt.com/products/sluice-2)
